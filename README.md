# Голосовой суфлёр

Суфлёр для чтения английского текста с iPad во время записи экрана.

- `index.html` — единственный исходник. Он же артефакт в Claude:
  https://claude.ai/artifact/SHAKXV29dfWWX5Kwo5iNsZ (перевод делает Claude, на iPad листается касанием).
- `docs/` — копия для GitHub Pages, собирается командой `./build_pages.sh`
  (голос через распознавание речи Safari, перевод Google, запасной — MyMemory).
- `tests/test_logic.js` — проверки разбивки текста и сверки речи: `node tests/test_logic.js index.html`.

Перевод между версиями переносится кнопкой «Скопировать с переводом» и вставкой через «+ Текст».

Главный способ: `python3 make_link.py сценарий.json` собирает ссылку, в которой уже лежат строки и перевод
(после «#», на сервер не уходит). Открыл ссылку на iPad — сценарий загружен, нажал ▶ — суфлёр ведёт голосом.
